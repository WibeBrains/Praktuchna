**Виконав:** [ім’я], адміністратор бази даних.

## Що зберігатимемо

Обрали PostgreSQL. У цій базі дані зберігаються в таблицях, пов’язаних між собою.

| Таблиця | Основні поля |
|---|---|
| Клієнти | Номер клієнта, ім’я, телефон |
| Автомобілі | Номер авто, номер клієнта, марка, модель, держномер |
| Майстри | Номер майстра, ім’я, спеціальність, кваліфікація |
| Бокси | Номер боксу, назва |
| Записи | Номер запису, номер авто, номер майстра, номер боксу, початок, завершення, стан |
| Роботи | Номер роботи, номер запису, назва роботи, вартість |
| Запчастини | Номер позиції, номер запису, назва, характеристики, кількість, ціна за штуку, постачальник, очікувана дата, стан замовлення |

«Номер» — це унікальний номер рядка в таблиці. Наприклад, номер клієнта в таблиці автомобілів показує, кому належить авто.

У таблиці «Запчастини» один рядок — одна замовлена деталь або кілька однакових деталей для конкретного ремонту. У характеристиках можна описати кастомну деталь, наприклад її розмір чи матеріал.

## Як пов’язані таблиці

- Один клієнт може мати кілька автомобілів.
- Один автомобіль може мати багато записів на ремонт.
- Один майстер може виконувати багато записів у різний час.
- В одному боксі може бути багато записів у різний час.
- Один запис може містити кілька робіт і запчастин.

## Основні правила

Один бокс або майстер не може бути зайнятий двома ремонтами одночасно. Час завершення має бути пізніше за час початку.

Стан запису: «заплановано», «у роботі», «завершено» або «скасовано». Стан замовлення запчастини: «замовлено», «отримано» або «скасовано».

Історія автомобіля — це його завершені записи з роботами та запчастинами. Окрема таблиця для історії не потрібна.

Загальна вартість = сума вартості робіт + сума (кількість запчастин × ціна за штуку). У розрахунок входять отримані та використані в ремонті запчастини. Ціни завершеного ремонту зберігаємо, щоб його сума не змінювалася.
